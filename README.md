# Postman Коллекция — Diploma Центр социального обслуживания

## Описание

Это основная Postman-коллекция для тестирования REST API Центра социального обслуживания.

**Коллекция содержит**:
- Авторизацию и работу с пользователями
- Управление клиентами и их классификацией
- Заявления/приложения
- Назначение и отслеживание услуг
- Расписание социальных работников
- Негативные сценарии и проверку прав доступа

## Структура коллекции

| Папка                    | Что тестируется                              | Основные методы          |
|--------------------------|---------------------------------------------|--------------------------|
| **Auth**                 | Авторизация, регистрация, logout            | POST, GET                |
| **Users**                | CRUD пользователей, экспорт, социальные работники | GET, POST, PUT, DELETE |
| **Clients**              | Классификация клиентов, назначение услуг    | POST, GET, PATCH, DELETE |
| **Applications**         | Заявления клиентов (будет добавлено)        | —                        |
| **Negative Tests**       | Негативные сценарии и проверка безопасности | —                        |

## Окружения (Environments)

В проекте используются следующие окружения:

1. **Diploma - Dev (Admin)** — аккаунт администратора (полные права)
2. **Diploma - Dev (User)** — обычный пользователь
3. **Diploma - Dev (Social Worker)** — социальный работник

**Важные переменные:**
- `base_url`
- `token`
- `clientId`, `user_id`, `assignmentId` и др.

## Как использовать

### 1. Импорт в Postman
- Открыть Postman
- Import → выберать файл коллекции
- Import → выберать нужное окружение

### 2. Настройка
1. Выберать окружение `Diploma - Dev (Admin)`
2. Запустить запрос `Auth → Login`
3. Дальше можно запускать остальные запросы

### 3. Запуск через Newman (CLI)

```bash
# Установка Newman
npm install -g newman

# Запуск коллекции
newman run "collections/Diploma — Центр социального обслуживания API.postman_collection.json" \
  -e "environments/Diploma - Dev (Admin).postman_environment.json" \
  --reporters cli,htmlextra \
  --reporter-htmlextra-export ../reports/report.html
